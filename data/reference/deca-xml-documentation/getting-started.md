# Getting started

In this part, you will learn the basics of creating monsters for RotMG using XML.

Following this guide and reading through the Documentation will allow you to create entirely viable and original entities for the game. Our goal at DecaGames is to give to you, design enthusiasts and RotMG fans, the tools and the ability to contribute to the future of the game.

We are looking forward to seeing all the amazing creations you can come up with!

## What is XML?

- XML stands for eXtensible Markup Language
- XML is a markup language much like HTML
- XML was designed to store and transport data
- XML was designed to be self-descriptive

If you are interested in learning more about XML, we recommend you to check the great tutorials at [W3schools](https://www.w3schools.com/xml/default.asp).
