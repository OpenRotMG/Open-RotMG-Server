# Swirl

**Effect:**

Move in a fast tight circle (gives facing)

**Attributes:**

- **speed** (float, default **2.0**): speed at which the monster moves
- **acceleration** (float, default **2.0**): rate at which the speed increases
- **turnRate** (float, default **Pi**): rate of turn (negative values send object in opposite direction)

**Examples:**

Pentaract Eye (if not Buzzing)

```
<Behavior>Swirl</Behavior>
```
