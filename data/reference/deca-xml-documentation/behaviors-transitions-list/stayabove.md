# StayAbove

**Effect:**

Monster will stay above a certain altitude (only in Realms)

**Attributes:**

- **minAltitude** (int, default **200**): altitude the monster will try to stay above, 200 is used for Mountains
- **speed** (float, default **0.5**): speed at which the monster moves

**Examples:**

Sandsman King

```
<Behavior minAltitude="24">StayAbove</Behavior>
```
