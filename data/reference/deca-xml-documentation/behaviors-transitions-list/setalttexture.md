# SetAltTexture

**Effect:**

Use an alternative texture

**Attributes:**

- **altTextureId** (int, default **0**): \<AltTexture id\="x"\> tag to use, specifies the texture

**Examples:**

The Puppet Master (Encore, when switching to teal bolt attacks)

```
<Behavior altTextureId="1">SetAltTexture</Behavior>
```
