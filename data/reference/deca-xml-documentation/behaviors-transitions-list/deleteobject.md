# DeleteObject

**Effect:**

Deletes nearby objects

**Attributes:**

- **objectId** (string, default empty): comma-separated list of objects to delete
- **radius** (float, default **0.0**): radius within which to delete objects

**Examples:**

Mad Lab Open Wall

```
<Behavior objectId="Blue Torch Wall" radius="4">DeleteObject</Behavior>
```
