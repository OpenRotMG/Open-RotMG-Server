# ChangeGround

**Effect:**

Changes the ground under the object / monster.

**Attributes:**

- **groundId** (string, default empty): id of the ground to use

**Examples:**

Hermit God Drop (Metamorphoses into OT portal)

```
<Behavior groundId="Grey Open">ChangeGround</Behavior>
```
