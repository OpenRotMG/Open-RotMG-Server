# CopyDamageRecord

**Effect:**

Copies damage record of nearby object

**Attributes:**

- **targetId** (string, default empty): name of object to copy record from
- **range** (float, default **40.0**): maximum distance of the object

**Examples:**

Hermit God Tentacle Spawner

```
<Behavior targetId="Hermit God">CopyDamageRecord</Behavior>
```
