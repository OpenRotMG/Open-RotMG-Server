# XML migration: selected differences and retained policies

Selected client identities and wire behavior remain authoritative. Recovered Release 7.0 rules (`data/game/123.5.1/actors.xml`, linked world and geometry XML) replace pre-migration Rust behavior (`79a4c92b`) where applicable. Authored continuity and source gaps are qualified in the XML; this does not authenticate exact 123.5.1 server behavior. See `docs/reference-sources.md` for the engine and loot allocation contract and `docs/xml-migration-test-map.md` for test scope.

| Area | Selected behavior / authority |
|---|---|
| Stheno and Realm portal rates | Recovered Stheno states, swarm Wander/Shoot/6 s Decay and radius-8 guardians; Medusa→Abyss `.04`, Flying Brain→Lab `.02`, Ghost God→Lair `.04` (`actors.xml`). XML authority replay checks a changed Medusa roll and Stheno rules under the same binary. |
| Dungeon clear and exits | `game.xml` `Clear` explicitly selects scripted births, Victory portal, authored Realm return, or no exit. Arachna, Septavius, Dr Terrible and Davy retain authored Realm returns; Locker direct placement does not load the recovered exit-bearing summoner. Cellar `VictoryAtDeath` publishes `0x71d` to Nexus, not old `0x712`; its shielded phases replace legacy rage chase. |
| Manor, Lab, Tomb | Manor Coffin Creature self-Decay gives no XP; Ruthven's Regular coffin throws and bat orders replace hard-coded waves/death sweep. Lab cages use local Spawn; Open Wall requires Dr Terrible and all Tesla Coils gone. Lost room geometry is reconstructed: `CoilPlacement` puts two per last five power rooms (including Dr Terrible's). Tomb trap switch tosses up to six traps; heal/producer scope is linked type/group/ownership, not the legacy fixed roster. |
| Ship, Locker and Beachzone | Ship Anchor timer pauses while dormant; its final roll stamps zero or four Locker portals. Locker crew replacement is a new entity and lamps only replace via XML lifecycle. Party God's root Heal is independent of Stun and heals up to 3000 HP every 200 ms while damaged; old protected fixtures do not prove an earned Beachzone clear. |
| Ordinary actors and finite sites | Realm roots use linked `Terrain`, `SpawnProb`, `Spawn`, `PerRealmMax`; authored `RealmRules` owns density, ambient regrowth and finite named-site admission/terrain/anchors. XML operations own offspring. Procedural stamps are reconstructed, not historical maps. Quest level windows, Realm closure cycle and lineage semantics still use native policy (`src/quest.rs`, `src/endgame.rs`, `src/world/realm_voice.rs`). |
| Quest and loot credit | XML source rows select probabilities, thresholds, tiers and party-wide minima; journal uses effective damage and immutable encounter/recipient facts. No legacy bag-scatter RNG or forced packing parity. Quiver of Thunder private `.001` remains an explicitly authored Actual Greater Nature Sprite row; recovered input lacks it. |
| Source-linked behavior differences | Dreadstump wakes at any damage; Lair slime births jitter; Arachna uses the named `set_web`→`eat_flies` path; live spider sacs may hatch adjacent owned families; Abyss uses recovered overlay, not the legacy optional room rollback/lava seal. Oxygen vents sum up to 100; Thessal's Question uses case/whitespace-insensitive exact `PlayerSays` within 30 tiles for 15 s, no punctuation exception. |
| Executor defaults | `executor_defaults` in `src/content/game/compile.rs` owns defaults. Selected data uses retained literals where DECA differs: Explode `numShots=1`, Heal `range=8`, toss `defaultAngle=0`, ShowEffect `flashPeriod=1s`. Absent Heal caps mean unlimited, absent ReleaseSpawnAtDeath `max` means `min`, and absent Shoot `arcDegrees` means unrestricted facing; targeted/auto default angles are 0°/90°. |
| Durability and retention | The journal keeps unsettled/reconciliation rows. Settled rows compact to replay tombstones preserving identity/hash/status/result. Published settled history is pruned after 48 h once no longer held by its live world, or after 1 h for compacted progress-only events once no longer held (`src/store/world_events.rs`). A changed catalogue fingerprint is explicit reconciliation, not implicit replay. |
| Upstream continuity | Schema 25 adds the journal to upstream schema 24. Terminal XP is uncapped per kill. Hostile targeting skips new or teleported arrivals for 3 s. Hermit tentacles return toward their owned ancestor. Classic-layout lava stepping stones, full Godlands density/refill and the Trench's 21 spawn vents remain reconstructed. |
| Native dispatch boundaries | Template identities own route/registry admission; display titles remain UI/output. Selected container, merchant, pickup, player, deployment and companion identities still use native ownership/transaction services. Raw map/stamp geometry and protocol/class tags are not encounter fallbacks. |
